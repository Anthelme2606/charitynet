# CharityNet

C'est UN projet visant à fait une collecte de don

## Telechargement du projet

git clone https://github.com/Anthelme2606/charitynet.git

## Installation

Utiliser cette librairi [npm](https://www.npmjs.com/) pour istaller le projet.

## Usage

```bash


## Lancer Premierement l'api ##

# Entrer dans le dossier API
cd api

# Installer les dependance de l'API avec la commande
npm install

# Executer l'API avec la command
npm start

# Retour de l'execution (en local)
http://localhost:4000/graphql


#####################################################################


## Lancement du client ##

# Entrer dans le dossier client
cd client

# Installer les dependance du client avec la commande
npm install

# Executer le client avec la command
npm start

# Retour de l'execution (en local)
http://localhost:3000
```
